# June 14, 2026 - Daily Memory

## What Happened
- Investigated why Clyde reported "0 upcoming interviews" in the chat assistant when there were 3 upcoming interviews visible in the calendar.
- Discovered that Clyde's system prompt builder (`buildSystemPrompt` in `src/agentChat.js`) was slicing the first 10 events from the chronologically sorted array (`calendarEvents.slice(0, 10)`), which always returned the 10 oldest events (all in the past).
- Modified `buildSystemPrompt` to split the calendar events into past and future based on the current time, and then slice the 5 most recent past events and the next 10 upcoming events.
- Added a unit test in `test/agentChat.test.js` to assert that calendar events are correctly filtered relative to the current time, showing both recent past events and future upcoming ones.
- All unit tests pass successfully.
- Fixed an issue where the chat assistant outputted literal escaped newlines (`\n`) and raw markdown formatting (such as `###` and `**`).
- Updated `renderAgentMessageContent` in `src/renderer/App.jsx` to unescape `\\n` to actual newlines, and implemented a custom inline and block-level markdown parser to render headings, bold/italic text, and lists dynamically in the UI instead of rendering raw markup as plain text.
- Built and validated the updated Vite renderer bundle successfully.
- Investigated why Clyde was unable to read/find the Google job description in the Pinecone database when "All Sources" is active.
- Diagnosed two issues:
  1. The local SQLite database stores job descriptions with type `'jd'`, but `allUploadedKnowledgeSources()` was only querying items of type `'upload'`.
  2. The Pinecone query failed with a 400 Bad Request error because the user's settings generate 768-dimensional Gemini embeddings, whereas the `clyde-copilot` index has dimension 3072. Since `searchKnowledgeVectors` lacked a try-catch block, this error crashed the entire chat message flow.
- Actions taken:
  1. Added a try-catch block inside `searchKnowledgeVectors` in `src/pineconeClient.js` to log Pinecone query failures and return an empty array, preventing the chat from crashing.
  2. Updated `allUploadedKnowledgeSources()` in `src/agentChat.js` to retrieve and combine both `'upload'` and `'jd'` type items from `knowledgeManager.listKnowledge()`.
