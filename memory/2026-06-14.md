  2. Updated `allUploadedKnowledgeSources()` in `src/agentChat.js` to retrieve and combine both `'upload'` and `'jd'` type items from `knowledgeManager.listKnowledge()`.

  2. Updated `SettingsDrawer` (settings tab `'context'`) in `src/renderer/App.jsx` to move the Pinecone input fields inside the custom LLM provider block (`llmProvider !== 'clyde-cloud'`). This hides them for the managed Clyde Cloud path where credentials/connections are automatically provisioned and managed backend-side.
