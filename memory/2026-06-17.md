# 2026-06-17 - Custom Hotkeys Implementation

Today, I worked on the custom keyboard shortcuts request.

## Accomplished
- Relocated the Nudge hotkey to a new **Hotkeys** section under **Settings > General**.
- Created 6 new settings fields for:
  1. Toggle capture protection (`toggleCaptureProtectionHotkey` - Default: `Ctrl+Shift+P`)
  2. Toggle Stealth Taskbar Mode (`toggleStealthTaskbarHotkey` - Default: `Ctrl+Shift+H`)
  3. Toggle minimize/maximize window (`toggleMinMaxHotkey` - Default: `Ctrl+Shift+M`)
  4. Screenshot & Ask Clyde (`screenshotAskHotkey` - Default: `Ctrl+Shift+D`)
  5. Suggested Questions (`suggestedQuestionsHotkey` - Default: `Ctrl+Shift+Q`)
  6. End Call (`endCallHotkey` - Default: `Ctrl+Shift+E`)
- Handled settings defaults propagation in `main.js` and `App.jsx`.
- Refactored hotkey keyboard recorder in `App.jsx` to be dynamic and reusable.
- Implemented global shortcut registration in `main.js` when capture starts, alongside active hotkey refresh upon save settings.
- Added event bindings to `preload.js` and subscriptions in the renderer.
- Supported focused local keydown fallbacks within `ActiveCapturePanel`'s `useEffect`.
- Verified successfully using Vite compilation and full renderer smoke tests.
- Fixed font and color readability in the Preflight modal and End Call confirmation modal under `theme-snow` and `theme-blossom` by overriding CSS variables to their high-contrast defaults inside these dark-background containers, setting `color-scheme: dark`, and overriding input styling variables inside these modals.
- Relocated the Hotkeys section from the General settings tab into its own dedicated "Hotkeys" tab within Settings, adding the tab button, updating the tabs navigation grid from 6 to 7 columns, and verifying through successful build compilation and smoke test runs.
