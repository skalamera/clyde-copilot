# 2026-06-11 — Vercel API Endpoints Consolidation

## Context
Consolidated five Stripe/billing-related serverless endpoints in `website/api` into a single dispatcher `api/billing.js` to bring the total number of functions from 13 down to 9, complying with Vercel's Hobby plan limit of 12 serverless functions.

- Deleted the 5 legacy files from `website/api/` to avoid Vercel building separate functions for them.
