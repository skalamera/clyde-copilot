# 2026-06-11 — Vercel API Endpoints Consolidation

## Context
Consolidated five Stripe/billing-related serverless endpoints in `website/api` into a single dispatcher `api/billing.js` to bring the total number of functions from 13 down to 9, complying with Vercel's Hobby plan limit of 12 serverless functions.

## What Was Done
- Modified `website/vercel.json` to add URL rewrites for:
  - `/api/create-checkout-session` -> `/api/billing?action=create-checkout-session`
  - `/api/create-billing-portal-session` -> `/api/billing?action=create-billing-portal-session`
  - `/api/create-pro-signup-checkout` -> `/api/billing?action=create-pro-signup-checkout`
  - `/api/activate-pro-checkout` -> `/api/billing?action=activate-pro-checkout`
  - `/api/entitlements` -> `/api/billing?action=entitlements`
- Created `website/api/billing.js` consolidated backend endpoint dispatching to the 5 billing logic blocks.
- Deleted the 5 legacy files from `website/api/` to avoid Vercel building separate functions for them.
- Updated `website/test/billing.test.mjs` to read from the consolidated `api/billing.js` instead of the individual files.
- Successfully ran and passed all 8 website billing tests.
